## 6.1 Transformer 与生成

### 6.1.1 编码器、解码器与推理

原始 Transformer 面向序列到序列任务：编码器用双向自注意力读取输入，解码器用因果自注意力读取已有输出，并通过交叉注意力访问编码器表示。各层还有前馈网络、残差连接和归一化；Pre-LN 与 Post-LN 的顺序不同，不能把一种排列当作所有模型的结构。

自回归生成先编码输入，再逐 token 预测；decoder-only 将提示和输出组织为同一因果序列，不需要独立编码器和交叉注意力。它与下一 token 预测目标相配，便于统一文本任务与生成接口。不能据此推断双向注意力必然低秩、表达能力较弱，或 decoder-only 在所有 zero-shot 任务中最优。KV cache 也可用于 encoder-decoder 的解码阶段，并非 decoder-only 专属。

### 6.1.2 Attention 与掩码

$$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V.$$

Self-attention 的 Q、K、V 来自同一输入的不同投影；cross-attention 的 Q 来自解码器，K、V 来自编码器。加性掩码 M 在允许位置为 0、屏蔽位置为负无穷；必须在 softmax **之前**应用。避免整行全部屏蔽，否则可能出现 NaN。不同库的布尔掩码约定可能相反，要核对接口。

原始架构与数学依据：[Attention Is All You Need](https://arxiv.org/abs/1706.03762)。代码实现见第 03 章 3.2–3.5。

## 6.2 激活函数与梯度

### 6.2.1 为什么需要非线性

仅堆叠线性或仿射层，整体仍是线性或仿射映射。激活函数使网络能拟合更复杂的非线性关系；这不意味着包含激活的整个神经网络仍是线性的。

### 6.2.2 梯度消失与爆炸

反向传播沿链式法则累乘 Jacobian。深度、权重尺度、激活饱和和序列长度共同影响梯度，不能简化为“所有局部梯度小于 1 就消失”。ReLU 可缓解部分饱和问题，也可能出现死亡单元，不能保证消除梯度消失。

合理初始化、残差路径和归一化有助于稳定训练；梯度裁剪主要限制过大的梯度，不能恢复已经消失的梯度。RNN/LSTM 的时间维度讨论见第 03 章开头。

## 6.3 微调与内存效率

### 6.3.1 Fine-tuning 与 PEFT

微调从预训练权重继续适配任务或领域，可采用监督任务、继续语言建模或偏好目标，并不只指监督分类。基本流程是：选模型 → 整理并划分数据 → 确定可训练参数和目标 → 训练与调参 → 在独立数据上评估。不要重新随机初始化需要迁移的主干权重。

全量微调通常更新全部主干参数；PEFT 只训练少量已有参数或新增参数，主要节省梯度、优化器状态及每个任务的增量存储。冻结主干不代表所有激活都可省略，也不保证所有任务达到全量微调性能。

| 方法 | 更新什么 | 需要区分的概念 |
|---|---|---|
| 选择性层、稀疏微调、任务头 | 选定层、参数子集或输出头 | PEFT 不等于只更新最后几层 |
| Adapter、软提示 | 新增的小模块或可训练提示 | 主干通常冻结 |
| LoRA | 低秩更新矩阵，W = W₀ + BA | 近似的是更新，不是把整个模型替换成低秩模型 |
| LISA | 周期采样的中间层，结合持续训练的嵌入和输出层 | 是层级采样策略，不等于 LoRA |
| GaLore | 在低秩梯度空间维护更新，再映射回参数空间 | 可支持全参数训练，不宜笼统列为只训练少量参数的 PEFT |

正则化约束参数变化或模型复杂度，本身不会自动减少可训练参数量。来源：[LoRA](https://arxiv.org/abs/2106.09685)、[LISA](https://arxiv.org/abs/2403.17919)、[GaLore](https://arxiv.org/abs/2403.03507)。

### 6.3.2 量化、剪枝与蒸馏

量化降低数值表示精度，剪枝移除连接、通道或模块，蒸馏让学生模型学习教师行为。降低位宽、参数量或理论运算量，并不自动带来实际加速：还取决于内核、稀疏格式、硬件、批量和 KV cache。FP32 转 FP16 通常称为降低浮点精度；不能直接等同于整数低比特量化。

AWQ 是使用校准激活的权重量化方法。先选择逐输入通道缩放，在浮点下保持等价，再降低量化后的重构误差；这里的 clipping 是校准时搜索权重裁剪阈值，不是梯度裁剪或训练正则化。本项目 W4A16 主要作用于语言层，视觉塔仍为浮点；纯文本校准不能称为图文联合校准。见 [AWQ 论文](https://arxiv.org/abs/2306.00978) 和 [代码解析](coding.md#awq)。

## 6.4 提示、上下文学习与评估

### 6.4.1 CoT 与 ICL

Zero-shot CoT 用提示引导生成中间步骤；few-shot CoT 在上下文提供带步骤的示例。这里改变的是推理条件，没有自动更新模型参数，输出的解释也不保证等同于内部计算过程或保证正确。

ICL 通过指令、上下文或示例改变条件预测：P(下一个 token | 提示、示例、已有输出)。它与训练阶段的参数更新应分开讨论。System 1 / System 2 是对快速联想和多步推理的类比，不能据此断言某类题目模型必然能做或不能做。

### 6.4.2 压缩后的安全比较

浮点与量化模型需要使用相同输入、生成参数和独立评审规则。先报告有效标注数量与覆盖率，再比较指标；缺失回答和未标注结果不能算“安全”。基准清单、文献与本项目的统计口径统一见 [多模态安全实践](../03%20Transformer与大模型入门/practices/mllm-compression-safety/README.md)。
